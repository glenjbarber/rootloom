# rootloom

`rootloom` is the repository for **Milestone0**, focused on integrating large language models running on premises.

The name plays on the `root@lolhost $` shell-prompt joke.

## Brand assets

- `assets/logo.svg` — light-background wordmark
- `assets/logo-dark.svg` — dark-background wordmark
- `assets/mark.png` — woven local-compute graphic
- `assets/favicon.ico` — multi-size favicon
