## Initial focus

The initial focus is integrating large language models that run on premises. This page records the currently established scope framing, not implementation status or a complete technical design.

The shared coordination policy establishes that constituent projects integrate through versioned external wire contracts and may provide optional adapters. Projects must not depend on one another through internal imports. API contracts are documented in their owning repositories.
